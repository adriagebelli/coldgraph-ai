# ColdGraph AI

ColdGraph AI utilitza un graf de coneixement empresarial dinàmic i models predictius per redactar i enviar hiperpersonalitzacions de màxima rellevància basades en l'estat operatiu públic del client potencial.

## Arquitectura
- **Backend**: Python amb Flask
- **Base de dades**: Supabase (PostgreSQL)
- **IA**: OpenAI API
- **Frontend**: HTML5 amb Tailwind CSS

## Instal·lació
1. Clonar el repositori
2. Instal·lar dependències: `pip install -r requirements.txt`
3. Configurar variables d'entorn al fitxer `.env`
4. Executar l'aplicació: `python app.py`
